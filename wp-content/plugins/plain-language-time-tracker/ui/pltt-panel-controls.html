Panel-level controls

One rule: a control lives where its effect ends. Changes everything below it → page level. Changes one panel → that panel's header.

This adds a third tier the spec doesn't have. Panel controls are styled quieter than page controls, so the hierarchy itself tells you how far the change reaches before you touch anything.

The test, when it's unclear: change the control, then look at the stat figures above. If they change too, it's page level. If only the panel redraws, it's panel level.

A chart switching between day/week/month is showing the same data at different granularity — page figures don't move, so it's panel level. A control that changes which period the page covers moves the figures, so it's page level even if it sits next to a chart.

What moved

The Full / By month toggle currently sits above the chart at full weight, reading like a page control. If it only changes the chart's granularity, it belongs in the chart's header at panel weight — as shown. If it changes the period the whole page covers, it isn't a chart control at all and should be folded into the date control's presets.

Worth checking in the code which it actually does — that determines where it goes.

03

Sorting and grouping

Different mechanisms, deliberately.

Sorting is a property of a column, so it lives on the column header — clickable, with a caret, WP-native. Grouping restructures the whole table, so it's a control in the panel header. Keeping them separate means the column headers stay honest: a caret means "sort by me" and nothing else.

Rules

Sortable columns get a muted caret. The active one darkens, its caret turns blue and points, and it's the only column showing direction. Not every column needs to be sortable — only ones you'd plausibly order by.

Group by is a panel-header dropdown. When grouping is off, the bands disappear and the table is flat. Sorting then applies across the whole table; when grouping is on, sorting applies within each band.

Group bands carry the group name, its count, and its total — the same shape as the day bands in Entries, so one component serves both.

Why the weight difference matters

Two segmented controls that look identical but reach different distances is the kind of thing that makes an interface feel unpredictable. Making panel controls visibly lighter means you can tell, before clicking, whether something will redraw one chart or the whole page.

Panel controls never persist across navigation. Page-level scope — filters and period — should.
