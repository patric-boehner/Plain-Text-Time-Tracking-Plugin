Retainer

Scope is one closed period.

The structural difference: an hourly scope is a run of entries with no natural end, a retainer scope is a calendar month. The period is the unit, so the third figure counts from when the period closed, not from the oldest entry.

Why two figures for one fact

Total hours and Over allocation look like duplication, but they answer different questions: how much work happened, and how much of it you can charge for. In an hourly scope those are the same number, which is why hourly needs only one.

The percentage lives on the basis line rather than as its own figure. That's where the dropped meter's information goes — 191% stated once, in text, next to the hours it describes.

03

Fixed budget

Does this have a billing context at all?

Question before designing it

The working model has been that fixed-fee projects use time tracking for over/under awareness only — no billing record machinery, because the fee is agreed up front and invoiced in Zoho on its own schedule. If that's still true, a fixed-budget project never appears in Ready to bill and there is no billing scope block to design.

If it isn't true — if you record a bill against a fixed-fee project when you deliver, or for a deposit or a milestone — then it needs a figure set, and the set below is the starting point. Worth settling before building, because it also determines whether fixed-budget rows appear in the Billing index at all.

If it is built

The entry table below it would have no per-entry amounts to select — the fee doesn't derive from hours — so "Review & bill" wouldn't open a selection list. It'd go straight to the record dialog with the fee pre-filled. That's a different flow from the other two, which is another reason to confirm it's needed before building it.
