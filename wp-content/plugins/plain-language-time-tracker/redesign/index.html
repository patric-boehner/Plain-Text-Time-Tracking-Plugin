A fresh shape for the Time Tracker

Read only from the code, then redrawn from scratch. Same soul — jot plain text → process the day → confirm the guesses → see it → bill it — but structured around the four things you actually do, instead of the fourteen screens that grew over time.

7 menu items → 4 3 "a day" screens → 1 3 billing entry points → 1 Hidden project type → explicit Still 100% WP-admin native

The one idea

The whole product is a single pipeline. The current build breaks that pipeline across separate pages that you navigate between — capture on one screen, process on another, review in a table, edit back on the first. The redesign treats the pipeline as one continuous surface per job, and demotes everything that's really just configuration.

Five deliberate moves

1 · One surface that evolves — not four screens

Capture stays a plain journal: typing only autosaves — nothing forms below, nothing to react to, so the flow of jotting is never interrupted. When you're done, one deliberate Process parses the whole day and the same screen evolves (capture → processed → settled) instead of throwing you to a Review table and back. The end-of-day ritual is kept, the screen-hopping isn't. Past days sit behind a Today · History toggle.

2 · Make project type an explicit first choice

Hourly / Monthly retainer / Fixed budget / Internal — picked up front, revealing only the fields that matter. Today the type is silently inferred from four different columns, and the form shows every field with JS hiding/showing them.

3 · One home for billing

A single queue of everything outstanding, grouped by client, with one "Review & bill" sheet. Replaces the Invoicing page, the inline Reports panel, and the per-project billing surface — three doors to the same room.

4 · Predictions as a visible trust surface

The learned guess shows why it guessed and confirms in one tap, turning dashed → solid. The learning that already exists finally looks like it's working, which is what earns the tap.

5 · Insights reports; it doesn't bill

Reporting and money are different jobs. Insights answers "where did my time go"; Billing answers "what do I send." A one-line bridge connects them ("$1,240 unbilled outside this range → Billing").

What stays sacred

Plain-text capture, the @time/#tag/done grammar, learned aliases, the four project types and their billing math, the immutable "what was billed" record. The engine is good — this is about the shape wrapped around it.
